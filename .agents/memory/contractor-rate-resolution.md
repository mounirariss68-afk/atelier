---
name: Contractor rate resolution
description: Durable precedence and approval basis for contractor time costs.
---

Resolve contractor cost rates for each work date, not from the current roster value or the week start. A non-equity partner plan wins unless an engagement term explicitly permits an override; otherwise use the effective engagement term, then the roster fallback.

**Why:** Engagement terms can differ by project and change mid-week. Using one current or week-level rate makes payment proposals, self-billing, and project margin disagree.

**How to apply:** Any new contractor-cost consumer must use the shared work-date resolution boundary, retain entry evidence, split payable/self-billing buckets when rate or currency changes, and treat lead-validated time as payable-ready while accepting later legacy approval states.
